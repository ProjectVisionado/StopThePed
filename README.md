# 🇪🇸 StopThePed - Full Español de España

## 🏢 Project Vision

**Project Vision** presenta **StopThePed - Full Español de España**, una traducción completa y adaptada al español de España.

El objetivo es ofrecer una experiencia natural, clara y cómoda para la comunidad española de **LSPDFR**.

## 🛡️ Seguridad y confianza

Esta traducción ha sido realizada por **Project Vision**, manteniendo el funcionamiento original de StopThePed y centrando el proyecto en su localización al español de España.

**Project Vision** busca ofrecer una traducción segura, estable y de confianza para la comunidad.

## 📌 Versión

**Versión actual: `v0.1`**

Esta es la primera versión pública del proyecto.

Como se trata de una versión inicial, pueden existir pequeños errores de traducción o textos que necesiten correcciones. Estos serán revisados y mejorados en próximas versiones.

## 🐛 Soporte

Si encuentras algún error o problema relacionado con la traducción, próximamente publicaremos un **correo electrónico y/o Discord oficial de soporte** donde podrás comunicarlo.
